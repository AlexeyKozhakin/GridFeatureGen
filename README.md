# GridFeatureGen

GridFeatureGen — это инструмент для обучения и инференса нейронных сетей, предназначенных для 
прогнозирования городского ландшафта на основе данных LIDAR, с выводом результатов в формате 2D.

## Последовательность запуска скриптов для подготовки данных (Обучения НС)

1. **Анализ количества точек**
   ```bash
   python aalysis_number_points.py
   ```
   Анализирует количество точек в датасете.

2. **Определение нижнего порога точек и удаление ненужных файлов**
   ```bash
   python filter_dataset.py
   ```
   Удаляет файлы, которые не соответствуют пороговому значению.

3. **Генерация датасета с фичами**
   ```bash
   python generate_features.py
   ```
   Создает датасет с признаками (фичами) на основе имеющихся данных.

4. **Анализ расстояний**
   ```bash
   python statistics_max_mean_distance.py
   ```
   Вычисляет статистику максимальных и средних расстояний между точками.

5. **Разделение на сильно испорченные данные**
   ```bash
   python filter_geatures_pt.py
   ```
   Фильтрует данные по качеству и определяет испорченные точки.

6. **Построение изображений для проверки**
   ```bash
   python generate_images.py
   ```
   Генерирует изображения на основе обработанных данных.

## Последовательность запуска скриптов для подготовки данных (Предсказания НС)
1. **Анализ количества точек в LAS файлах**
   ```bash
   python aalysis_number_points.py
   ```
   Анализирует количество точек в датасете.

2. **Определение нижнего порога точек в LAS файлах и при необходимости добавление точек в файлы**
   ```bash
   python add_points_to_dataset.py # пока нет такого скрипта
   ```
   Добавляет точки в файлы, которые не соответствуют пороговому значению.

3. **Генерация датасета с фичами**
   Очень важно сделать удобно, чтобы можно было добавлять новые фичи. И пользоваться функцией универсально
   если это train то добавлять класс точки, если это предикт то не добавлять (либо это делается само, если нет, то выводится
сообщение (при необходимости) о том, что есть class или нету)
   ```bash
   python generate_features.py
   ```
   Создает датасет с признаками (фичами) на основе имеющихся данных.

4. **Анализ расстояний**
   ```bash
   python statistics_max_mean_distance.py
   ```
   Вычисляет статистику максимальных и средних расстояний между точками. Главное знать в каком столбце эта точка.

5. **Разделение на сильно испорченные данные**
   ```bash
   python filter_geatures_pt.py
   ```
   Фильтрует данные по качеству и определяет испорченные файлы, где по какой-то причине оказались расстояния превосходящие
некоторый порог, для того чтобы в дальнейшем визуализировать и найти в чем причина.

6. **Построение изображений для проверки**
   ```bash
   python generate_images.py
   ```
   Генерирует изображения из тензоров, с возможностью выбора тех каналов которые нужны. Должна быть возможность схранять
как много канальные цветные и даже с глубиной (так и одноканальные серые)


## Последовательность запуска скриптов для пост-обработки данных предсказаний
Файлы после предсказания это тензоры, такие же как и на входе в модель. Теперь нужно просто сделать из них shape файлы 
качественные без шума и с максимальной стороной прямой.


1**Объединение тензоров с предсказаниями**
```bash
python join_tensors.py
```
Объединение предсказанных тензоров исходя из имен по столбцам и строкам. Если тензоров не хватает 
до наполнения до полного прямоугольника заполняется дефолтными тензорами без класса.

2**Очистка от шумов**
```bash
python remove_noise.py
```
Очищение от шумов в данных, для того чтобы подготовить данные для выделения истинных данных для оконтуревания.

3**Выделение контуров и сохранение в shape files**
```bash
python generate_conturs_save_shape.py
```
Очищение от шумов в данных, для того чтобы подготовить данные для выделения истинных данных для оконтуревания.

## Дополнительная информация

Из подготовленных очищенных тензоров генерим контуры и сохраняем их в shape file
