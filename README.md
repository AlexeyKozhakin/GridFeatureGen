# GridFeatureGen

GridFeatureGen - это инструмент для анализа и предобработки данных, включающий фильтрацию, генерацию признаков и построение изображений.

## Последовательность запуска скриптов

1. **Анализ количества точек**
   ```bash
   python aalysis_number_points.py
   ```
   Анализирует количество точек в датасете.

2. **Определение нижнего порога точек и удаление ненужных файлов**
   ```bash
   python filter_dataset.py
   ```
   Удаляет файлы, которые не соответствуют пороговому значению.

3. **Генерация датасета с фичами**
   ```bash
   python generate_features.py
   ```
   Создает датасет с признаками (фичами) на основе имеющихся данных.

4. **Анализ расстояний**
   ```bash
   python statistics_max_mean_distance.py
   ```
   Вычисляет статистику максимальных и средних расстояний между точками.

5. **Разделение на сильно испорченные данные**
   ```bash
   python filter_geatures_pt.py
   ```
   Фильтрует данные по качеству и определяет испорченные точки.

6. **Построение изображений**
   ```bash
   python generate_images.py
   ```
   Генерирует изображения на основе обработанных данных.
